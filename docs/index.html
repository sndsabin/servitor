First Launch Security Warnings (Unsigned Release)

Because current releases are unsigned, your operating system might show a security warning when opening the application for the first time.

macOS (.dmg)

macOS may block the app stating it “cannot be opened because it is from an unidentified developer.”

How to run:
  1. Open System Settings → Privacy & Security.
  2. Scroll down to the Security section.
  3. Locate the notification for Servitor and click Open Anyway.
  4. Enter your system password or use Touch ID to confirm.
Official Apple Guide

Windows (.exe)

Windows Defender SmartScreen may show a blue window stating “Windows protected your PC.”

How to run:
  1. Click the "More info" link inside the blue window.
  2. Click the "Run anyway" button that appears at the bottom.
